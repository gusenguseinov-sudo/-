# Школа продаж (Android)

Обучающая игра для сотрудников торгового зала: викторина по характеристикам товаров и тренажёр диалогов с покупателями.

Приложение — это Android-обёртка (WebView), внутри которой работает игра из `app/src/main/assets/index.html`.
Вопросы и диалоги редактируются прямо в этом файле (массивы `QUIZ` и `DIALOGS`).

## Сборка
- Bitrise: файл `bitrise.yml` собирает debug-APK. Gradle wrapper создаётся автоматически на первом запуске.
- Локально: установите Android Studio и откройте папку проекта.
